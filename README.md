# Housing
Buy or Rent? Make a wise decision for your house.

## 模型说明

通过逐年现金流模拟，比较**买房**与**租房+投资**两种策略的总成本，寻找使两种策略等价的「临界投资回报率」。

核心参数：
- `purchase_price`：房价
- `annual_appreciation`：年房价涨幅（租金涨幅与之联动）
- `rent_price_ratio`：年租售比（年租金 / 房价）
- `annual_maintenance_rate`：年维护费率
- `invest_return`：租房方将首付款投入市场的年化收益率
- `buy_discount_rate`：购房打折/税费比例

## 核心结论

### 1. 临界公式

**临界投资回报率 ≈ 房价年涨幅 + 年租售比**

> 例：房价年涨 3%，租售比 1%，则投资回报需超过 **4%** 才值得租房；否则买房更划算。

买房的隐性综合回报 = 资产增值（appreciation）+ 省下租金（rent_price_ratio），投资必须超过这个组合收益才能让租房占优。

### 2. 各因素影响力排序

| 因素 | 对临界回报率的影响 | 结论 |
|---|---|---|
| `annual_appreciation` | **高**，近似 1:1 线性，1%→7% 对应临界值 2%→7% | 最关键变量 |
| `rent_price_ratio` | **高**，近似 1:1 线性，0.5%→2.5% 对应临界值 3.4%→5.6% | 第二关键变量 |
| `annual_maintenance_rate` | **低**，0.5%→4% 仅使临界值变动约 0.07% | 可忽略 |
| `buy_discount_rate` | **极低**，0→50% 打折仅使临界值变动约 0.013% | 几乎无影响 |
| `purchase_price` | **零影响**，曲线完全水平 | 模型与绝对房价无关 |

### 3. 基准场景结果（300万，70年，涨幅3%，租售比1%）

- 买房总成本（净）：**-602万**（期末房产价值覆盖全部持有成本，净盈利）
- 租房+5%投资：**-5350万**（资产从300万增至5650万）
- 在 5% 投资回报率下，租房大幅胜出；低于 4% 临界点时，买房占优

### 4. invest_return 的非线性威力

租房侧的投资组合复利增长，`invest_return` 超过临界点越多、年限越长，优势呈**指数级放大**。70年内 5% 投资回报 vs 4% 临界点，租房最终组合价值比买房净值高出数千万量级。

## 决策建议

```
if invest_return > annual_appreciation + rent_price_ratio:
    → 租房 + 投资更划算
else:
    → 买房更划算
```

对中国一线城市（涨幅假设 3%，租售比约 1%~1.5%），临界投资回报率约为 **4%~4.5%**。能长期稳定跑赢此门槛，租房具备财务优势；否则买房是更稳健的选择。
